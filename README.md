## 🚀 Highlights & Features

- **Dynamic 3D Centerpiece**: Three.js WebGL kinetic gemstone and fluid sine wave mesh with interactive vibe presets (`Prismatic Core`, `Cyber Wave`, `Solar Flare`).
- **Interactive Video Color Grading Slider**: Real-time drag comparison between RAW S-Log3 and 4K Master graded footage with Film HUD, timecode, and audio visualizer.
- **Dual Themes**: Seamless switch between Dark Mode and warm Editorial Ivory Day Mode with contrast-validated readability.
- **Brand Palette Copy Tool**: One-click hex swatch copying for showcasing design systems.
- **SEO & Google Search Optimized**: Complete Schema.org JSON-LD structured data (Person, WebSite, ProfessionalService), OpenGraph cards, Twitter cards, `sitemap.xml`, and `robots.txt` for top Google search rankings.
- **Tactile Micro-interactions**: Magnetic buttons, 3D tilt effects, cursor glint tracking, and film grain texture.

## 💻 Local Development

Clone the repository and run the local development server:

```bash
# 1. Clone repo
git clone https://github.com/<your-username>/lokesh-portfolio.git

# 2. Navigate to directory
cd lokesh-portfolio

# 3. Install dev dependencies
npm install

# 4. Start local preview server
npm run dev
```

Open `http://localhost:8080` in your browser.

---

## ☁️ Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your `lokesh-portfolio` repository.
4. Framework Preset: **Other** (Root directory: `./`).
5. Click **Deploy**. Your portfolio will be live in seconds with global edge CDN caching and SSL certificates.
